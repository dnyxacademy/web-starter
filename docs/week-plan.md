# The four weeks

Monday 2 November to Saturday 28 November 2026. Monday to Saturday, Sunday off. Plan on three to
four hours a day.

The ticket for each day, with its due date, is in your Dnyx Learn lesson. The full brief for each
assignment — what to practise, the steps, a worked example, the "Done when" check and how it is
marked — is in [MERN-Assignments](https://github.com/dnyxacademy/MERN-Assignments).

## The rhythm

| Day | What happens |
|---|---|
| Mon | The week's tickets are released. Lesson, then build |
| Tue | Lesson and build. Written stand-up in the batch chat before 10 am, every day |
| Wed | Hands-on workshop with a trainer |
| Thu | Lesson and build. Draft pull request for early feedback |
| Fri | Build. Demo, five minutes each, in small groups. Fun Friday |
| Sat | Weekly quiz. Submission by noon. Placement Spotlight session. Mentor feedback in the evening |
| Sun | Off |

## Week 1 (2-7 Nov) - Foundations and a static prototype

How the web works. Git, GitHub and the pull request flow. Semantic HTML, forms, accessibility
basics. CSS: selectors, box model, flexbox, grid, responsive design. JavaScript: variables,
functions, arrays, objects, the DOM, events, `fetch` and JSON, async and await.

**By Saturday:** a responsive static prototype, deployed to Netlify or Cloudflare Pages.
**By Wednesday:** your first pull request, however small.

## Week 2 (9-14 Nov) - Modern front end, typed

Tailwind CSS. Modern JavaScript: modules, destructuring, async and await. TypeScript: types,
interfaces, unions, typing API data. React: components, props, state, effects, lists, keys, routing,
custom hooks, context, and forms with React Hook Form and Zod. npm and a bundler.

**By Saturday:** your front end rebuilt in React and TypeScript. Mid-point review this week.

## Week 3 (16-21 Nov) - Next.js, backend and PostgreSQL

The heaviest week, and it has a Saturday catch-up hour. Next.js App Router, layouts, server and
client components, data fetching, validation with Zod, deploying to Vercel. Node.js and Express:
routes, middleware, errors, REST design. SQL and PostgreSQL on Neon, Prisma and migrations. An
overview of MongoDB and Firebase, so you know when documents fit.

**By Saturday:** the app on Vercel, a CRUD API on PostgreSQL, and a schema diagram.

## Week 4 (23-28 Nov) - Sign-in, test, ship, demo

Authentication: password hashing, JWT or sessions, protected routes, environment variables, CORS,
and the basics of injection, XSS and rate limits. Connecting the front end to the live API.
Testing: Vitest, Supertest, one end-to-end flow in Playwright, and CI with GitHub Actions.
AI-assisted engineering: instruction files, prompt libraries, MCP servers, and the cautions.

**Demo Day is Friday 27 November.** Final submission Saturday 28 November by noon.

### The final project has to have

- Sign-in
- At least three related tables in PostgreSQL
- A Next.js front end in TypeScript
- Input validation
- At least eight automated tests, including one end-to-end flow
- A deployed front end and API
- A README with setup, your decisions and the limitations
- A two-minute demo video
- A short "How I used AI" note
